# My Space

Portafolio personal desarrollado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: estilos y diseño adaptable a móviles.
- `script.js`: pequeñas interacciones de navegación.

## Publicación
Se puede publicar con GitHub Pages desde Settings → Pages → Deploy from a branch → `main` → `/(root)`.
